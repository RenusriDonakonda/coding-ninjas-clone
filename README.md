# 🚀 Coding Ninjas Inspired Website Redesign (Slab-2)
### Frontend Developer Internship Project

A modern responsive frontend project developed as part of a Frontend Developer Internship.  
The project focuses on redesigning the Coding Ninjas-inspired homepage with a clean UI, improved user experience, and reusable React components.

---

## 📌 Project Overview

This project is a frontend implementation of a learning platform homepage inspired by the Coding Ninjas website.

The goal of this project was to:

- Build a modern educational platform landing page
- Create reusable React components
- Implement responsive layouts
- Design sections similar to the original Coding Ninjas website
- Improve UI consistency with an orange & white theme
- Practice frontend development concepts using React and Tailwind CSS

---
